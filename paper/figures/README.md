# Publication figures

Only report-ready figures generated from traceable experiment outputs belong
here. Record the originating experiment ID in the figure filename, caption, or
adjacent manuscript source. Large raw artifacts belong under ignored artifact
paths, not in the paper directory.

Prefer vector PDF for plots and diagrams, and high-resolution PNG only for
raster renderings. A generated figure should be reproducible from a versioned
script and saved data; do not manually edit measured curves. Captions must state
the evaluated split, sample count, aggregation, and uncertainty definition when
those details affect interpretation. Conceptual figures must be labeled as
schematic rather than experimental evidence.
