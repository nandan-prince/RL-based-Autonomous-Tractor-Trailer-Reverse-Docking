# MuJoCo scenes

This directory stores complete generated logistics-yard and loading-dock MJCF
worlds. The implemented `nominal_dock_v1.xml` contains the nominal vehicle and
implements `configs/environments/nominal_dock_v1.yaml`.

The nominal bay interior is `x in [0, 6]`, `y in [-0.75, 0.75]`, with the
opening at `x = 6`, the back wall at `x = 0`, `0.10 m` wall thickness, and
`1.00 m` visible wall height. Collision geoms keep the same planar outline but
are extruded above every chassis to preserve the 2D footprint-collision rule.
The target trailer yaw is zero and docking error is measured at the named
`docking_point` site.

`nominal_dock_v1.xml` is generated by `../builder.py` and is self-contained: the
vehicle is produced by the same generator function as the standalone model
rather than pulled in with an MJCF `<include>`. Do not edit it by hand.

Scene-only lights, cameras, materials, and visual yard context may vary without
changing experiments. Wall and obstacle collision geometry, target pose, and
success tolerances may not drift from the environment configuration. Keep a
minimal deterministic scene suitable for automated headless tests.
