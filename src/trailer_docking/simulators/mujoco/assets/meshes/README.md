# Meshes

Optional visual meshes belong here. They are appearance assets only: use simple
MJCF primitives for collision so experiments do not depend on decorative mesh
topology or scale.

For every added asset, record its source, author, license, units, coordinate
axes, and any transformation applied. Do not commit an asset without confirmed
redistribution rights. Prefer compact open formats and keep large source files
outside Git when they are not required to reproduce a result.
